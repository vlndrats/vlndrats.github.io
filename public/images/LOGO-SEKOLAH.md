# Logo sekolah

Simpan gambar logo di folder ini dengan nama berikut:

- logosma.png: SMAN 19 BANDUNG
- logosmp.png: SMPN 35 BANDUNG
- logosd-langensari.png: SDN 01 LANGENSARI
- logosd-padasuka.png: SDN 064 PADASUKA

Ekstensi .jpg dan .jpeg juga didukung otomatis. Gunakan nama file huruf kecil.
Jika ada beberapa format, urutan prioritasnya PNG, JPG, JPEG.
Gunakan gambar persegi, disarankan minimal 128 x 128 piksel.
Gambar ditampilkan utuh tanpa dipotong. Jika logo belum ada, ikon sekolah tampil.

Setelah menambahkan gambar, refresh halaman. Untuk versi produksi,
jalankan build dan deploy ulang agar gambar baru ikut dipublikasikan.
