# Media showcase Sinister Battlegrounds (SA-MP)

Taruh 3 foto screenshot aplikasi di folder ini:

- `hud.png` (atau `1.png`) — screenshot HUD modern CEF saat bermain (health, armor, kompas, killfeed)
- `inventory.png` (atau `2.png`) — screenshot sistem inventaris CEF drag-and-drop & looting
- `gameplay.png` (atau `3.png`) — screenshot skydive / parachuting / gameplay battle royale

### Ketentuan Format:
- Mendukung format: `.png`, `.jpg`, `.jpeg`, atau `.webp`.
- Resolusi disarankan 16:9 (minimal 1600 x 900) agar tampil penuh (*full edge-to-edge*) tanpa sisa tepi hitam.
- Gambar otomatis ditemukan saat build tanpa perlu mengubah baris kode.
- Dapat diperbesar ke resolusi penuh melalui tombol perbesar (maximize) pada kartu proyek.
