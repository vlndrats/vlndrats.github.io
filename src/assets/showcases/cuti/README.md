# Media showcase SiCuti — Employee Leave Management System

Taruh 3 foto screenshot aplikasi di folder ini:

- `karyawan.png` (atau `1.png`) — screenshot portal mandiri karyawan / pengajuan cuti
- `admin.png` (atau `2.png`) — screenshot panel admin / persetujuan cuti & log riwayat
- `kalender.png` (atau `3.png`) — screenshot kalender jadwal cuti tim

### Ketentuan Format:
- Mendukung format: `.png`, `.jpg`, `.jpeg`, atau `.webp`.
- Resolusi disarankan 16:9 (minimal 1600 x 900) agar tampil tajam dan penuh tanpa tepi hitam (*full edge-to-edge*).
- Gambar otomatis ditemukan saat build tanpa perlu mengubah baris kode.
- Dapat diperbesar ke resolusi penuh melalui tombol perbesar (maximize) pada kartu proyek.
