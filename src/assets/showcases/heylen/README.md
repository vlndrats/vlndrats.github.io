# Media showcase heylen.id

Taruh media di folder ini, lalu refresh dev server. Untuk produksi, build dan deploy ulang.

Total 3 media (2 foto dan 1 video):
- dashboard.png — screenshot dashboard belajar (foto 1)
- chat.png — screenshot tutor AI (foto 2)
- demo.mp4 — video demo singkat (video)
- demo-poster.jpg — cover video (opsional)
- demo-id.vtt — subtitle Indonesia (opsional)
- demo-en.vtt — subtitle Inggris (opsional)

Gambar mendukung .png, .jpg, .jpeg, atau .webp; video .mp4 atau .webm.
Gunakan nama file persis seperti di atas, huruf kecil. Jika ada beberapa format,
prioritas gambar PNG > JPG > JPEG > WebP; video MP4 > WebM.
Media otomatis ditemukan saat build, tidak perlu mengedit kode.

Disarankan screenshot 16:9 minimal 1600 x 900, video MP4 H.264 20–45 detik
yang memperlihatkan dashboard > chat > kuis > multiplayer. Hindari data pribadi.
Video diputar atas klik pengunjung, tanpa autoplay, dan berhenti saat slide diganti.
Screenshot ditampilkan utuh (object-contain), bisa diperbesar lewat tombol galeri.
Jika media belum ada, kartu pengantar fitur akan tampil. Kartu ini bukan screenshot.

Deskripsi proyek disesuaikan dengan source heylen-ai: React/TypeScript, Express,
Gemini API, Firebase Auth/Firestore, tutor dengan lampiran, kuis solo/multiplayer,
unggah materi, riwayat, XP, streak, leaderboard. Tidak mengklaim angka pengguna,
peningkatan hasil belajar, streaming respons, maupun status deployment.
