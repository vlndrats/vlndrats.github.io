# Media showcase Point of Sale (POS) & Multi-Branch Inventory

Taruh 1 foto screenshot aplikasi di folder ini:

- `pos.png` (mendukung `.png`, `.jpg`, `.jpeg`, atau `.webp`) — screenshot antarmuka Kasir (POS) / Manajemen Stok & Gudang

### Format & Ketentuan:
- Gunakan nama file `pos.png` (atau format gambar lain seperti di atas).
- Prioritas format: PNG > JPG > JPEG > WebP.
- Disarankan resolusi 16:9 (minimal 1600 x 900) agar tampil penuh (full edge-to-edge) dan tajam.
- Gambar otomatis ditemukan saat build tanpa perlu mengubah baris kode.
- Dapat diperbesar ke resolusi penuh melalui tombol perbesar (maximize) pada kartu proyek.
